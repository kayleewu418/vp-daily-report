# vp-daily-report

从 VP 日报 Excel 中读取最新业务数据，生成两段可直接使用的日报文案：

- `概览解析-AI颜色版`
- `车系数据解析-AI颜色版`

当前正式脚本为 `VP日报自动化/scripts/calc_vp_daily_report.py`。脚本仅使用 Python 标准库，不需要安装第三方包。仓库中的 R 脚本仅作历史参考，不再维护最新业务口径。

## 快速使用

在仓库根目录执行：

```powershell
python "VP日报自动化\scripts\calc_vp_daily_report.py" `
  "C:\path\to\VP日报_20260916.xlsx"
```

脚本默认从 `VP日报_YYYYMMDD.xlsx` 文件名推断运行日期，并将前一天作为目标日期。例如：

```text
输入文件：VP日报_20260916.xlsx
运行日期：2026-09-16
目标日期：2026-09-15
```

也可以明确传入运行日期和输出路径：

```powershell
python "VP日报自动化\scripts\calc_vp_daily_report.py" `
  "C:\path\to\source.xlsx" `
  2026-09-16 `
  "outputs\vp_daily_fields_20260916.csv"
```

或者直接指定目标日期：

```powershell
python "VP日报自动化\scripts\calc_vp_daily_report.py" `
  "C:\path\to\source.xlsx" `
  --target-date 2026-09-15
```

`run_date` 和 `--target-date` 不能同时使用。默认输出文件为 `outputs/vp_daily_fields.csv`，编码为 UTF-8 with BOM，可直接用 Excel 打开。

## 运行前检查

脚本直接读取 XLSX 文件中已经保存的单元格值，不会启动 Excel，也不会重新计算公式。因此，运行前需要先在 Excel 中完成数据刷新并保存文件。

至少确认以下内容已经更新到目标日期：

1. `线上官渠潜客客流` 第 1、2 行
2. `销售过程数据走势` 中全系、G9L、GX、L03 的日期和指标值
3. `各车系当日数据` 的当日及月累数据
4. `月累环比 (2)` 的锁单和转化率数据

官渠客流或主要趋势指标缺少当前周期、比较周期日期时，脚本会直接报错并停止输出，避免使用旧数据生成日报。G9L 试驾是唯一允许部分日期缺失的趋势指标，具体规则见下文。

## 日期比较规则

脚本根据目标日期自动选择比较周期。

| 目标日期 | `compare_rule` | 文案口径 | 当前值 | 比较值 |
| --- | --- | --- | --- | --- |
| 周一 | `prev_week_weekday_avg` | 上一周周中日均 | 周一当日值 | 上周一至周五日均 |
| 周二至周五 | `previous_day` | 前一日 | 当日值 | 前一日值 |
| 周六 | `prev_weekend_avg` | 上周末日均 | 周六当日值 | 上周六、周日日均 |
| 周日 | `weekly_vs_last_week` | 上周 | 本周一至周日合计 | 上周一至周日合计 |

所有变化率统一按以下公式计算：

```text
变化率 = 当前值 / 比较值 - 1
```

周一和周六只有比较周期取日均，当前值仍为目标日当日值。周日当前周期和比较周期都取完整自然周合计。

## 概览解析口径

概览数据来自：

- `线上官渠潜客客流`
- `销售过程数据走势`

输出顺序固定为线上官渠潜客客流、门店客流、线索总量、试驾总量、锁单总量。

### 线上官渠潜客客流

从 `线上官渠潜客客流` 读取：

- 第 1 行：日期
- 第 2 行：对应日期的官渠客流

输出官渠客流趋势描述和变化率。趋势描述规则为：变化率大于 `0.1%` 写“有增长”，小于 `-0.1%` 写“下降”，其余写“基本持平”。

### 门店客流

从 `销售过程数据走势` 的 `全系` 区块读取 `客流`，输出趋势描述和变化率。

### 线索总量

输出顺序为：

1. 全系线索总量趋势及变化率
2. G9L 线索量、占全系线索比例及变化率
3. 全系非 G9L 线索变化率
4. GX、L03、其他车型线索变化率

不再输出线上线索和线下线索。衍生口径为：

```text
全系非 G9L 线索 = 全系线索 - G9L 线索
其他车型线索 = 全系线索 - G9L 线索 - GX 线索 - L03 线索
G9L 线索占比 = G9L 线索 / 全系线索
```

### 试驾总量

输出顺序为：

1. 全系试驾总量趋势及变化率
2. G9L 试驾量、占全系试驾比例及变化率
3. L03、GX、其他车型试驾变化率

L03 不再输出试驾量和占比，只输出相对比较周期的变化率。衍生口径为：

```text
其他车型试驾 = 全系试驾 - G9L 试驾 - GX 试驾 - L03 试驾
G9L 试驾占比 = G9L 试驾 / 全系试驾
```

G9L 试驾允许缺失：

- 当前周期缺失时，G9L 试驾量、占比和变化率显示 `/` 或“暂无可比数据”
- 日均比较周期只有部分日期有值时，只对有值日期求平均，并把文案口径写成“有值日均”
- 比较周期完全无值时，输出“暂无可比数据”
- 计算其他车型时，缺失的 G9L 试驾按 0 处理

### 锁单总量

全系、G9L、L03、GX 锁单直接读取 `销售过程数据走势` 的 `锁单` 行。全系锁单已包含 G9L，不能重复相加。输出顺序为：

1. 全系锁单总量及变化率
2. G9L 净锁单量、占全系锁单比例及变化率
3. L03 净锁单量及变化率
4. GX 净锁单量及变化率
5. 其他车型锁单量及变化率

其他车型口径为：

```text
其他车型锁单 = 全系锁单 - G9L 锁单 - GX 锁单 - L03 锁单
```

当前趋势表没有 G9L 锁单值时按 0 处理。

G9L 锁单当前周期有值、比较周期无值时，文案显示对应比较周期“暂无可比数据”。

### 衍生指标计算原则

所有“非 G9L”和“其他车型”指标都先按每个日期分别做减法，再根据比较规则求日均或合计，最后计算变化率。不能先分别计算各车系日均后再相减，否则在有效数据天数不一致时会产生错误结果。

## 车系数据解析口径

客流、线索和试驾读取 `各车系当日数据`：

| 指标 | 当日 | 月累 | 月累环比 | 月累同比 |
| --- | --- | --- | --- | --- |
| 客流 | B4 | B16 | B20 | B65 |
| 线索 | D4 | D16 | D20 | D65 |
| 试驾 | M4 | M16 | M20 | M65 |

当日锁单读取 `销售过程数据走势` 中目标日期的全系锁单。月累锁单及其环比、同比读取 `月累环比 (2)`；月累转化率按真实全系口径计算为 `月累锁单 / 月累线索`，转化率的环比、同比仍沿用表内百分比输出格式：

| 指标 | 月累 | 月累环比 | 月累同比 |
| --- | --- | --- | --- |
| 锁单 | T3 | U3 | V3 |
| 转化率 | T3 / `各车系当日数据!D16` | X3 | Y3 |

`各车系当日数据!M4` 与 `销售过程数据走势` 的全系试驾日值可能因统计口径不同而相差少量数据。脚本会输出提示，但不会中止：

- 概览解析使用 `销售过程数据走势` 的全系试驾
- 车系数据解析使用 `各车系当日数据!M4`

## Excel 结构要求

输入文件必须是有效的 `.xlsx` 文件，并包含以下工作表：

- `销售过程数据走势`
- `线上官渠潜客客流`
- `各车系当日数据`
- `月累环比 (2)`

`销售过程数据走势` 按第一列标签动态定位 `全系`、`G9L`、`GX`、`L03` 区块：

1. 车系名称所在行为区块起点
2. 下一行为日期行
3. 后续行按名称查找 `客流`、`线索`、`试驾`、`锁单`
4. 日期列可以随日报向右扩展，无需修改脚本列号

## 输出文件

CSV 每次写入两条记录，字段如下：

| 字段 | 含义 |
| --- | --- |
| `field` | 文案字段名 |
| `target_date` | 实际计算的目标日期 |
| `compare_rule` | 本次使用的日期比较规则 |
| `compare_label` | 文案中显示的比较周期名称 |
| `content` | 完整文案 |

脚本同时把完整文案打印到终端。数据缺失或工作表结构不符合要求时返回非零退出码，并在错误信息中列出缺失的指标或日期。

## 当前文案模板

```text
线上官渠潜客客流：官渠客流{趋势}，VS {比较周期}{变化率}；

门店客流：门店客流{趋势}，VS {比较周期}{变化率}；

线索总量：线索总量{趋势}，VS {比较周期}{变化率}；G9L 线索{线索量}（占线索总量比例{占比}），VS {比较周期}{变化率}；全系（非 G9L）线索 VS {比较周期}{变化率}；其中 GX{变化率}，L03{变化率}，其他车型合计{变化率}；

试驾总量：试驾总量{趋势}，VS {比较周期}{变化率}；G9L 试驾{试驾量}（占试驾总量比例{占比}），VS {比较周期}{变化率}；L03{变化率}，GX{变化率}，其他车型合计{变化率}；

锁单总量：全系锁单总量{锁单量}台，VS {比较周期}{变化率}；其中 G9L 净锁单{锁单量}台（占全系锁单比例{占比}），VS {比较周期}{变化率或暂无可比数据}；L03 净锁单{锁单量}台，{变化率}；GX 净锁单{锁单量}台，{变化率}；其他车型合计{锁单量}台，{变化率}。
```

```text
客流：{日期}日客流{当日值}，月累客流{月累值}，月累环比{环比}，月累同比{同比}
线索：{日期}日线索{当日值}，月累线索{月累值}，月累环比{环比}，月累同比{同比}
试驾：{日期}日试驾{当日值}，月累试驾{月累值}，月累环比{环比}，月累同比{同比}
锁单：{日期}日锁单{当日值}，月累锁单{月累值}，月累环比{环比}，月累同比{同比}
转化率：月累转化率{月累值}，月累环比{环比}，月累同比{同比}
```

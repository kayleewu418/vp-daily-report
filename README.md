# vp-daily-report

VP 日报自动化脚本，用于从指定 Excel 工作簿中读取日报所需数据，并输出两段可直接粘贴使用的文案：

- `概览解析-AI颜色版`
- `车系数据解析-AI颜色版`

主脚本：

```powershell
Rscript "VP日报自动化\scripts\calc_vp_daily_report.R" "C:\path\to\source.xlsx" "2026-07-30" "outputs\vp_daily_fields.csv"
```

说明：第二个日期参数是运行日期，脚本实际计算的是前一天，即 `target_date = run_date - 1`。例如传入 `2026-07-30`，输出对应 `2026-07-29`。

## 输出文件

默认输出：

```text
outputs/vp_daily_fields.csv
```

输出字段：

| 字段 | 含义 |
| --- | --- |
| `field` | 文案字段名，目前包括 `概览解析-AI颜色版`、`车系数据解析-AI颜色版` |
| `target_date` | 实际计算日期，即运行日期减 1 天 |
| `compare_rule` | 对比规则 |
| `compare_label` | 文案中的对比口径，例如 `前一日`、`上一周周中日均` |
| `content` | 最终生成的文案 |

## 对比口径

脚本会根据 `target_date` 是星期几自动选择对比口径。

| target_date 星期 | compare_rule | 文案显示 | 当前值 | 基准值 |
| --- | --- | --- | --- | --- |
| 周一 | `prev_week_weekday_avg` | 上一周周中日均 | 当日值 | 上周一到上周五日均 |
| 周二到周五 | `previous_day` | 前一日 | 当日值 | 前一日值 |
| 周六 | `prev_weekend_avg` | 上周末日均 | 当日值 | 上周六、上周日日均 |
| 周日 | `weekly_vs_last_week` | 上周 | 本周 7 天合计 | 上一周 7 天合计 |

环比/同比类百分比计算公式：

```text
rate = current / baseline - 1
```

## Excel Sheet 要求

输入 Excel 至少需要包含以下 sheet：

| Sheet 名 | 用途 |
| --- | --- |
| `销售过程数据走势` | 读取全系、GX、L03 等车系的客流、线索、试驾等每日走势 |
| `线上官渠潜客客流` | 读取线上官渠潜客客流 |
| `数据底表` | 读取锁单数据，尤其是全系、GX、L03 锁单 |
| `月累环比 (2)` | 读取 L03 月累线索/试驾，以及锁单、转化率的月累、环比、同比 |
| `各车系当日数据` | 读取车系数据解析中的客流、线索、试驾日值、月累、环比、同比 |

## 动态区块读取规则

部分 sheet 不是固定单元格读取，而是按第一列标签动态定位。

### `销售过程数据走势`

读取逻辑：

1. 第一列中查找车系名称：`全系`、`P7`、`G7`、`M03`、`P7+`、`G6`、`G9`、`X9`、`GX`、`L03`。
2. 车系名称下一行作为日期行。
3. 从车系名称下两行开始，到下一个车系名称前一行，查找指标行：`客流`、`线索`、`线上线索`、`线下线索`、`试驾`、`锁单`。
4. 指标行中每一列的值，和日期行同列日期对应。

### `数据底表`

读取逻辑：

1. 第一列中查找区块名称：`客流`、`线索（分渠道）`、`线索（分车系）`、`试驾`、`锁单`。
2. 当前脚本主要读取 `锁单` 区块。
3. 在 `锁单` 区块内查找 `总计`、`小鹏GX` / `GX`、`L03` 行。
4. 在这些行上方自动识别日期行。
5. 指标行中每一列的值，和日期行同列日期对应。
